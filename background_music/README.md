# Background Music Folder

Place your default background music files in this folder. The application will automatically load all audio files found here on startup.

## Supported Formats
- MP3
- WAV
- M4A
- OGG
- FLAC

## Usage
1. Add your background music files to this folder (e.g., `music1.mp3`, `music2.mp3`)
2. Restart the application
3. All tracks will be loaded into the background music pool

## How It Works
- All audio files in this folder are automatically added to the available background tracks
- When creating a podcast, one track is randomly selected from the pool
- The selected track is looped to match your podcast duration
- You can add more tracks through the UI, which will also be saved to this folder
