# Test Audio Files

This folder contains audio files used for testing the podcast creator application.

## Purpose
- Test audio files are committed to the repository
- Used for automated testing and demonstrations
- Other audio folders (intro_audio, outro_audio, background_music) are excluded from git

## Usage
Place test audio files here for:
- Unit testing
- Integration testing
- Demo purposes
- Documentation examples

Test files in this folder will be tracked by git.
