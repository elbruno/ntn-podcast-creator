# Outro Audio Folder

This folder includes the approved NTN outro used by the
[portable first-run settings](../../core/config.initial.json).
Existing saved selections always win. Only configurations missing an outro
selection discover an available file on startup.

## Supported Formats
- MP3
- WAV
- M4A
- OGG
- FLAC

## Usage
1. Add your outro audio file to this folder (e.g., `outro.mp3`)
2. Restart the application
3. Select the outro in **Settings** and choose **Save settings**

## Note
Additional local audio stays ignored by Git. Publish new audio only with
redistribution permission. See the [machine handoff guide](../../docs/MACHINE_HANDOFF.md).
