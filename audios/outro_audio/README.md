# Outro Audio Folder

Place your default outro audio files in this folder. The application will automatically load the first audio file found here on startup.

## Supported Formats
- MP3
- WAV
- M4A
- OGG
- FLAC

## Usage
1. Add your outro audio file to this folder (e.g., `outro.mp3`)
2. Restart the application
3. The outro will be automatically loaded and used for all podcasts

## Note
If multiple files are present, only the first one (alphabetically) will be used.
